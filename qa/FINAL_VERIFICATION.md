# Итоговая проверка — 2 ноября 2026

Основная платформа сдачи — локальный браузерный сервис Node.js/SVG. Figma-адаптер экспериментальный.

## Актуальная версия

- `npm test`: 38 passed, 0 failed: 13 core, 19 semantic, 6 HTTP. Повторный запуск после подключения локальной модели и исправлений независимого review.
- `npm run build`: собраны HTML, экспериментальный адаптер и три примера, выбранные настоящей моделью.
- `node scripts/launch.mjs --no-browser`: файлы модели проверены, сервер запущен на http://127.0.0.1:4173.
- Все 3024 значения path d из 40 вариантов каталога найдены без изменения в соответствующих исходных SVG S/L.
- Три итоговых SVG: корректный XML, уникальные ID, разрешённые внутренние ссылки; без image/script/foreignObject.
- Тесты проверяют общий масштаб, S/L, роли после перестановки, пустую сцену, более 10 экземпляров, палитры и clipPath для всех схем.
- Реальный encoder проверен на «Найти общий язык», «Копить на мечту», перефразировках, новых сценариях обучения/порядка/подарков и неподдерживаемых запросах. Выход ограничен ID каталога.
- HTTP-проверки: реальный подбор, готовность модели, повреждённый JSON, JSON null, превышение длины и 404.
- Независимый review подтвердил исправления: роли сохраняются при перестановке, устаревшая ошибка не перезаписывает новую сцену, JSON null получает 400.
- `demo/demo.mp4`: H.264, 1920×1080, 21 секунда. Три кадра просмотрены визуально; они показывают реальные результаты из examples/selections.json и соответствующих SVG, не запись UI.
- После восстановления браузера новая версия дополнительно проверена через UI: «Модель готова»; «Найти общий язык» → телефон/пазлы/фоновая ручка; «Копить на мечту» → кошелёк/монета/фоновая папка. Изменение формата на 1080×1080 подтверждено состоянием интерфейса.

## Что проверено в браузере ранее

В ходе работы проверены явный ввод «книга, телефон, пазлы», форматы, три палитры и импорт JSON, S/L, выбор слоя, фоновое состояние, дублирование, поворот, перемещение, удаление, отмена и скачивание SVG. Проверены desktop и узкое окно 520 px. Эти проверки подтверждают редактор; часть проходов выполнена до замены смыслового слоя. Новый смысловой слой отдельно проверен реальными вызовами модели и HTTP.

Файлы desktop/mobile/peach рядом относятся к промежуточным проходам и могут показывать предыдущий текст интерфейса. Они не являются финальной демонстрацией новой модели.

## Границы достоверности

- Полный повторный проход нового интерфейса и запись экрана не выполнены. После прежней остановки Computer Use управление восстановилось в новом обращении; оба смысловых сценария и квадратный формат подтверждены. Дальнейшая проверка палитры и снимок экрана столкнулись с тайм-аутами CDP. Снимок новой версии не сохранён; прежние проверки редактора и текущие тесты перечислены выше.
- Подбор ограничен 12 темами десяти исходных предметов. Ошибочные ассоциации, сложный контекст, отрицания и ирония остаются возможны. Прохождение набора тестов не означает понимание любой метафоры.
- Figma-адаптер не запущен в настоящем хосте. Импорт SVG в Figma и редактирование там отдельно не проверены; векторная структура документа проверена.
- Чистая установка на другой машине не проверена. Первые npm install и скачивание модели требуют интернета; дальнейший inference локальный.
- GitHub-репозиторий https://github.com/avtobus111/sborka-illustration-studio загружен; visibility=private и main подтверждены через API. Хеши всех 47 файлов и дерева Git совпали с локальными файлами. Доступ работодателю выдаёт владелец.
