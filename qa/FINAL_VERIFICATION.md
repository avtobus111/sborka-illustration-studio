# Проверка версии — 3 ноября 2026

Основная платформа — локальный браузерный сервис. Этот документ описывает текущие проверки; archive/ содержит протокол предыдущей версии.

## Текущие автоматические проверки

- npm test: **70 passed, 0 failed** — 23 core, 6 project, 33 semantic, 8 HTTP. В смысловых тестах используется настоящая локальная модель.
- npm run build: браузерный HTML, экспериментальный адаптер и три SVG-примера созданы одним движком.
- В 40 вариантах сохранены все 3024 исходных path d. Три итоговых SVG: корректный XML, уникальные ID, разрешённые ссылки, без image/script/foreignObject.
- Регрессии: обязательные предметы и синонимы, исключения через «без», положительный префикс «не про X, а про Y», «цветок», чистые списки, неизвестный «самолёт», производные «монетизация/телефония», сильная финансовая пара, вертикальное заполнение стандартного постера.
- Дополнительный независимый review ранее проверил 8448 геометрических сочетаний: границы, общий масштаб, лимит .16 для суммарных перекрытий главных предметов. В текущем проходе reviewer нашёл P2 широких основ «монет/телефон»; исправлено ограниченными словоформами, новые регрессии прошли.

## Проверки интерфейса и установки

Текущий UI подтвердил «книга и самолёт»: построена только книга, виден список нераспознанных слов и предложение выбрать замену. Создано отдельное окно студии и отдельный пустой файл Figma. После восстановления управления examples/02-savings.svg размещён в Figma как frame 02-savings 1080×1080 с вложенными группами object-3/object-4 и векторными слоями. Кошелёк object-3 выбран отдельно, X изменён с 73.713684 до 83.713684, размеры 792.48×498.18 сохранены. Снимок: ../demo/figma-import-proof.png.

В предыдущем проходе на этой же Windows-машине выполнены чистая npm-установка и первоначальная загрузка пяти файлов модели с SHA-256, затем build и ready=true. В той версии реальный браузер скачал SVG/JSON, а открытие скачанного проекта восстановило трансформации, включая поворот монеты 25°. Текущий HTTP-export дополнительно покрыт автоматическими тестами. Это не проверка на другом компьютере.

## Честные границы

- Смысловой охват ограничен десятью предметами и описаниями намерений. Сложные метафоры и отрицания могут требовать уточнения. Similarity не является вероятностью правильного ответа.
- qa/semantic-evaluation.json хранит исторические диагностические результаты предыдущей версии: 13/16 и 5/8 по ручным критериям. Эти фразы использовались в разработке; результаты не являются независимой статистической точностью и не заявляются замером текущей версии.
- Обычный semantic-подбор содержит 1–4 предмета; явно названные предметы сохраняются и сверх четырёх. Простые списки используют детерминированный parser, а не inference.
- Заполнение ≥60% высоты проверено для пары phone/puzzle на 1080×1440, balanced, S/L и трёх вариантов. Для title и произвольных пропорций такого обещания нет. Лимит перекрытия относится к автоматической раскладке 2–5 экземпляров, не ограничивает ручные правки.
- Импорт примера и перемещение отдельного предмета проверены в браузерной Figma; правка каждого контура и Desktop-хост отдельно не проверялись. Плагин остаётся экспериментальным.
- demo/demo.mp4 — пошаговый показ со снимками интерфейса предыдущего прохода и текущими результатами движка. Новый demo/walkthrough.mp4 — непрерывный 90-секундный захват одного окна через FFmpeg gfxcapture по HWND, H.264 1440×884, без аудиопотока. Полное декодирование прошло без ошибок; выборочно просмотрены кадры начала,25/50/75/86 секунд. Действие импорта Figma выполнено отдельно до записи. Неудачная GDI-проба с пустыми кадрами в комплект не включена.
- Новая мобильная проверка не подтверждена. Первый запуск требует Node.js20+ и интернета; после подготовки модель работает локально.

После согласованного изменения видимости репозиторий публичный; чтение исходников без авторизации проверено отдельно. Пароль Figma и веса модели не включены в комплект.
