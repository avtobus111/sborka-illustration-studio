# Итоговая проверка улучшенной версии — 2 ноября 2026

Основная платформа — локальный браузерный сервис. Figma-адаптер экспериментальный.

## Автоматические проверки

- npm test: 48 passed, 0 failed — 16 core, 5 project, 21 semantic, 6 HTTP.
- npm run build: собран HTML, адаптер и три примера из фактических ответов модели.
- Сохранены все 3024 исходных path d в 40 вариантах S/L. Три SVG-примера: корректный XML, уникальные ID и разрешённые ссылки, без растра и скриптов.
- Три варианта различаются при одинаковых ID, ролях, формате и расположении. Проверены малые, однообъектные и большие сцены, единый масштаб и границы холста.
- JSON roundtrip сохраняет ручные позиции, поворот, z-порядок, палитру и фон. Проверены пустая сцена, неизвестные ID, повреждённые данные, разные масштабы, лимиты и отдельный черновик ввода компонентов.
- Реальная модель: обычные запросы, перефразировки, неподдерживаемые темы, alternatives и needsReview. HTTP: подбор, готовность и невалидные запросы.

## Браузер новой версии

- «Модель готова», сборка «Учиться и сохранять фокус» и «Найти общий язык».
- Миниатюры: выбор 2 и 3; выбранный вариант сохраняется при смене формата.
- Палитры «Персик» и «Мята», исходники S, формат 1080×1440.
- Черновик «телефон» в режиме компонентов пережил перезагрузку до сборки. В библиотеке выделен только телефон; последующая сборка действительно создала один телефон.
- Слабый запрос «Удобный сервис всегда под рукой» открыл уточнение темы; прежняя сцена с телефоном осталась на месте.
- Выбор слоя телефона и поворот клавиатурой на 15° подтверждены снимком реального интерфейса demo/ui-02.png.
- Автосохранение: после перезагрузки восстановлены формат, S, палитра, вариант и ввод.
- Снимки desktop: 1440×900 CSS px; PNG может иметь больший размер из-за device scale factor.

## Независимый review

Найдены и исправлены два P2. (1) Восстановление не должно брать старые предметы сцены вместо незавершённого ввода — выбор восстанавливается из prompt. (2) Совпадение пользовательских цветов со встроенной палитрой не должно менять исходный фон — введён отдельный backgroundStyle с миграцией старых JSON. Для обоих сначала воспроизведены красные тесты, затем зелёный набор. Reviewer отдельно подтвердил закрытие обоих дефектов короткими Node-воспроизведениями.
