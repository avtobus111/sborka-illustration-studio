# Финальная проверка — 3 ноября 2026

Основная платформа — локальный браузерный сервис. Figma-адаптер экспериментальный.

## Установка и техника

- ZIP распакован в новую папку без node_modules и models. npm ci установил 55 пакетов; штатный setup-model скачал пять файлов закреплённой ревизии и подтвердил SHA-256. Сборка завершилась, сервер на тестовом порту 4174 сообщил ready=true. Это чистая папка на той же Windows-машине, не испытание на другом компьютере.
- Текущий набор npm test: 58 passed, 0 failed — 17 core, 6 project, 27 semantic, 8 HTTP.
- npm run build создаёт браузерный HTML, экспериментальный адаптер и три SVG из реального selector.
- Все 3024 исходных path d в 40 вариантах S/L сохранены. Итоговые SVG имеют корректный XML, уникальные ID и разрешённые ссылки, без image/script/foreignObject.
- Независимый review проверил 162 сочетания трёх специальных пар, S/L, трёх форматов, layout и вариантов: предметы внутри холста, конечный общий масштаб, heroId сохраняется в JSON.

## Проверки через интерфейс

- Обычная сборка, составной запрос «Мобильный банк помогает копить», выбор варианта, форматы, S, палитры и ручной поворот.
- После первоначального сбоя Blob-download введена выдача через HTTP attachment. Настоящий SVG скачан браузером: composition (4).svg; JSON: composition.sbor.json. Копии сохранены рядом как exported-final.svg и downloaded-final.sbor.json.
- Скачанный SVG разобран как XML: 247 path d принадлежат исходным библиотекам, растра и скриптов нет.
- Сцена изменена на одну книгу; затем через «Открыть проект…» выбран именно скачанный JSON. Вернулись кошелёк, монета и папка, 1080×1080, «Персик», hero wallet и поворот монеты 25°. DOM transform каждого предмета до сохранения и после открытия совпал точно.
- Открытие проверочного JSON также подтвердило сохранение ручных положений, слоя и палитры. Автосохранение восстанавливает сцену и незавершённый ввод.
- SVG и JSON через HTTP проверены на MIME, attachment, nosniff, корректность содержимого и отказ невалидным данным. Сервер получает только проект с ID каталога и сам строит SVG; посторонняя разметка не принимается.

## Смысловое качество

- 16 диагностических фраз были оценены до изменения и затем использовались для разработки. Финал: 13/16 по ручным критериям состава вместо исходных 7/16. Это не независимая точность. Отбор лишних предметов намеренно строже промежуточного варианта.
- Reviewer заранее зафиксировал восемь новых фраз: первый независимый результат 5/8. Найден P2 явного отрицания: кошелёк попадал в «не про деньги, а про музыку». Исправлено построением всех векторов из положительной части этой конструкции; регрессионный тест прошёл.
- Эти восемь фраз затем стали регрессионными. Финальный результат по прежним строгим критериям — 5/8. Читальный уголок, литературная глава и вечер головоломок могут потребовать выбора другой темы или явных предметов. Наличие needsReview сохраняет прежнюю сцену, но не гарантирует идеальных предложений.
- Состав теперь 1–4 предмета: намерение задаёт смысловые опоры, описания предметов и части фразы — остальной состав, метаданные контекста ограничивают отвлекающие ассоциации. Пустой ответ допустим для неподдерживаемой темы.
- qa/semantic-evaluation.json содержит критерии и результаты без заявления статистической точности.

## Review и ограничения

Независимый reviewer подтвердил закрытие P2 отрицания и не нашёл новых P1/P2 в двух export routes и UI form. В живых HTTP-проверках проверены опасный title, неизвестные ID, лишние поля, пустой/raw SVG и превышение размера. Геометрия и hero roundtrip прошли.

Повторный снимок вкладки студии не завершился из-за CDP timeout. Попытка снимка общего окна Chrome была запрещена автоматической проверкой, потому что там была выбрана сторонняя вкладка YouTube; после отказа это окно не использовалось. Проверки файлов выполнены через разрешённую вкладку самой студии. Внутренняя chrome://downloads также не использовалась после отказа URL policy.

Запрошенный viewport 520 фактически остался 2048 по DOM, поэтому новая мобильная проверка не заявляется; override сброшен. Импорт в живой Figma Desktop не проверен. Прежние снимки UI в demo относятся к предыдущему проходу того же интерфейса; три результирующие композиции пересобраны текущим selector. Видео — пошаговый показ, не непрерывная запись экрана.
