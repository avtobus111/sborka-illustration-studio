# Дизайн студии

Режим: Operate. Центральная задача — выбрать исходные объекты, собрать и скорректировать сцену, получить SVG.

Светлая студия с тремя областями: библиотека 236 px, гибкий холст и параметры 246 px. Тёмно-синий основной акцент #233D67; фон рабочего пространства #F4F5F7; границы #E4E6EB. Исходные иллюстрации задают цвет композиции, UI сохраняет нейтральность.

Шрифт — локальный Inter/Segoe UI с системным резервом, без загрузки из сети. Заголовки короткие, рабочие; нет рекламных блоков. Поле запроса, кнопка сборки и SVG-экспорт находятся в первом экране.

Холст SVG поддерживает выбор, перетаскивание и клавиатурное перемещение. Панель объектов отражает выбранный слой. На узком экране рабочая область идёт первой, библиотека и параметры — ниже. При prefers-reduced-motion переходы выключаются.

Цветовые схемы результата отделены от интерфейса и хранятся в каталоге. Все цветовые изменения результата проходят через валидатор палитры и ролевое сопоставление.
