# Сборка — векторная студия

Тестовое задание: заголовок или метафора → подбор существующих предметов → автоматическая композиция → редактирование → SVG.

## Запуск

Требуется **Node.js 20+** (проверено на Node.js 22). В Windows откройте **START.cmd**. При первом запуске он установит зависимости через npm, проверит/скачает открытую модель и откроет http://127.0.0.1:4173. Установка требует интернета; после подготовки модель работает локально, без внешнего AI API и без ключа. Если веса уже включены в ZIP, повторного скачивания не будет.

Другой способ:

```sh
npm ci
npm run setup:model
npm run build
npm start
```

Модель и токенизатор занимают примерно 135 МБ. В Git и архив исходников они не включены: setup скачивает файлы из зафиксированной ревизии Hugging Face и проверяет SHA-256. Файл assets/model-manifest.json содержит размеры и контрольные суммы. При ошибке модель не подменяется словарём: интерфейс сообщает проблему, явный выбор предметов остаётся доступным.

При запуске через START.cmd сервер работает в фоне. Лог: studio.log. Остановка сервера, запущенного вручную через npm start: Ctrl+C. Повторный START.cmd использует существующую студию. Отдельный dist/index.html позволяет работать по объектам, но для смыслового режима всё равно нужен запущенный локальный сервер.

## Демонстрация

Короткий видеопоказ: [demo/demo.mp4](demo/demo.mp4), 21 секунда. В нём показаны три реальных результата модели и общего SVG-движка, их запросы, выбранные темы и роли предметов. Это показ результатов, не запись интерфейса. Кадры можно воспроизвести скриптом scripts/render-demo.mjs при установленном FFmpeg.

Сценарий самостоятельной проверки в приложении:

1. Ввести **Найти общий язык** и нажать «Собрать»: телефон, пазлы и фоновая ручка.
2. Ввести **Копить на мечту**: кошелёк, монета и фоновая папка.
3. Переключить формат, цветовую схему, S/L; выбрать объект, изменить его состояние и поворот, порядок слоёв.
4. В режиме «По объектам» ввести **книга, телефон, пазлы**, собрать композицию.
5. Скачать SVG. Исходные пути остаются векторными и сгруппированы по предметам.

Заголовок управляет подбором; он не добавляется текстом в рисунок. Режим «Место под заголовок» резервирует свободную область для последующей вёрстки.

## Смысловой подбор

Используется настоящая pretrained модель **Xenova/paraphrase-multilingual-MiniLM-L12-v2**, quantized ONNX, через **Transformers.js 3.8.1**. Модель кодирует целую фразу; cosine similarity сопоставляет её с описаниями 12 смысловых тем доступной библиотеки. Для темы заданы подходящие ID предметов и роли. Это sentence encoder с поиском по ограниченной библиотеке, а не генеративная языковая модель и не универсальное понимание любой метафоры.

Поддерживаемые области соответствуют исходным предметам: общение, сотрудничество, сбережения и бюджет, обучение, внимание, порядок в делах, планы, музыка, подарки, идеи, цифровые инструменты. Неподдерживаемые и слабые неоднозначные запросы могут быть отклонены; пользователь уточняет смысл или выбирает предметы явно. Отрицания, ирония и сложные переносные значения могут давать несовершенный результат. Модель никогда не добавляет предмет за пределами каталога и не генерирует изображений.

## Соответствие заданию

- 10 исходных предметов × два состояния × S/L = **40 реальных вариантов**, плюс три фона для каждого размера.
- Исходные SVG-пути не перерисовываются. Для всех предметов сцены используется **единый равномерный масштаб**, сохраняющий их относительные размеры.
- Два сценария: метафора/заголовок и явные названия компонентов.
- Автоматическая композиция с главным и фоновым планами, варианты расположения, разные форматы, свои размеры.
- Перемещение, поворот, дублирование, удаление, состояния, порядок слоёв, отмена/повтор.
- Три исходные схемы и загрузка палитры JSON с автоматической перекраской всей сцены.
- SVG сохраняет векторность; изображения-растр, внешние шрифты и новые иллюстративные объекты не добавляются.

## Палитра

JSON: `background` — три оттенка фона от светлого к тёмному; `objects` — три акцента и, необязательно, два нейтральных цвета (тёмный и белый). Формат — #RRGGBB. Пример: examples/palette-example.json. Фон не получает акценты объектов, исходный белый нейтральный декор сохраняется. Невалидный импорт не меняет сцену.

## Экспериментальный адаптер Figma

Папка figma-plugin содержит адаптер вставки SVG и экспорта выделения. Он **не проверен внутри Figma Desktop** и не является основной платформой сдачи. Проверенная платформа — самостоятельный браузерный сервис. Для разработки плагина нужен Figma Desktop и собственный дизайн-файл с правом редактирования. Может потребоваться заменить локальный id в manifest.json на ID, выданный Figma. Смысловой режим в iframe требует доступного локального сервера и соответствующего сетевого разрешения; текущий manifest не запрашивает внешнюю сеть.
