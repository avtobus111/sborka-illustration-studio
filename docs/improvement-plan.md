# Усиление результата перед сдачей

Цель: дать дизайнеру несколько действительно разных композиций, честный выбор при неоднозначном смысле и возможность продолжить работу после перезагрузки. Используем существующие Node.js, MiniLM и SVG; исходную графику, пропорции и правила палитры сохраняем.

Решения агента в рамках просьбы улучшить результат как можно быстрее: дорабатываем текущую студию; облачный AI с ключом и замена интерфейса не нужны. Папка проекта выделена для этого тестового; проверенный предыдущий ZIP сохраняется в work как точка возврата.

1. **Композиции.** В core.mjs — три разных пространственных схемы для малых сцен, общий масштаб и укладка в безопасную область. Вариант не меняет выбранный пользователем формат и режим места под заголовок. Три SVG-миниатюры справа, смена без повторного запроса к модели. Тесты: разные координаты при тех же ID/ролях; границы, единый масштаб, S/L, все главные и все фоновые, место под текст в вертикали и горизонтали, уникальные ID превью.
2. **Работа с проектом.** Отдельный project.mjs сериализует только параметры сцены и ID каталога. JSON сохраняет позиции, поворот, z-порядок, формат, палитру и режим ввода. При восстановлении проверяются версия, библиотека, размер, число объектов, конечные значения и единый масштаб; чужая геометрия не принимается. Автосохранение localStorage и меню «Проект» с сохранением/открытием JSON. Тесты: точный round-trip, пустая сцена, вредные/повреждённые данные, разные масштабы, неизвестные ID.
3. **Неоднозначный смысл.** semantic.mjs возвращает до трёх подходящих тем с исходными ID и ролями. Слабый/близкий результат помечается needsReview; UI предлагает выбор, сохраняя прежнюю сцену. Уверенный запрос собирается сразу. Неподдерживаемая тема не получает выдуманных объектов. Тесты настоящей модели и действующего API; similarity не называется вероятностью.
4. **Проверка и сдача.** Общий набор тестов; сравнение исходных path; просмотр контактного листа композиций. Один проход desktop/mobile, одна общая правка при найденных дефектах. Обновить три SVG и демо, инструкцию и архитектуру; независимый итоговый review; загрузить в существующий приватный репозиторий без изменения доступа и обновить ZIP.

Вне рамок: новые иллюстрации, публичный хостинг, приглашение работодателя, универсальное понимание любой метафоры, обещания трудоустройства. Работа ведётся последовательно в текущей сессии.
