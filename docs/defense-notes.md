# Как показать и объяснить решение

## Показ за две минуты

1. Запустить START.cmd и дождаться «Модель готова». Для первого запуска нужны Node.js 20+ и интернет; далее смысловой подбор работает локально.
2. Ввести «Мобильный банк помогает копить». Показать, что подбор объединяет цифровой и финансовый смысл. Раскрыть выбранную тему; при неоднозначном запросе выбрать трактовку вручную.
3. Сравнить три миниатюры, выбрать формат и палитру, переключить S/L. Объяснить, что S/L — разные исходные SVG, а не один рисунок в двух размерах.
4. Выбрать слой, повернуть или переместить предмет, скачать SVG. Предметы остаются отдельными группами с исходными путями.
5. Сохранить JSON-проект, изменить сцену и открыть файл обратно. Показать сохранённые ручные правки.
6. В «По объектам» ввести «книга, телефон, пазлы» и собрать явно заданный набор.

## Архитектура простыми словами

Библиотека содержит исходные SVG-варианты десяти предметов: S/L и главное/фоновое состояния. Encoder MiniLM превращает текст в векторы. Двенадцать широких намерений задают одну-две смысловые опоры; остальные предметы подбираются по собственным описаниям и частям составного запроса. Поэтому состав сцены меняется внутри одной темы. Явно названные предметы обязательны; чистый список разбирается по названиям. Неизвестные слова в режиме компонентов показываются пользователю. Результат ограничен ID каталога, содержит роли, смысловой центр и краткие причины выбора. Новые изображения не генерируются.

Раскладчик учитывает смысловой центр, несколько правил взаимодействия пар и общий размер группы. Он нормализует границы и применяет один равномерный масштаб ко всем предметам. Пользователь исправляет результат вручную. При автоматической перекомпоновке позиции сбрасываются; отмена позволяет вернуть их.

Экспорт строится из исходных путей. Сервер принимает только проверенный JSON проекта, самостоятельно получает геометрию из каталога и выдаёт файл attachment. Произвольная SVG-разметка не импортируется в проект. Браузерный черновик хранится локально; перенос между компьютерами — через JSON.

## Решения и ограничения, которые стоит проговорить

- Самостоятельный веб-сервис выбран из разрешённых в задании вариантов. Адаптер Figma экспериментальный и не заявлен как проверенная платформа.
- Локальная модель позволяет запуск без внешнего AI API и ключа. Цена решения — загрузка примерно 135 МБ весов и ограниченное понимание сложного контекста.
- Это семантический поиск по метаданным и правила сцены. Генеративный LLM не используется. Ирония, редкие ассоциации и сложные отрицания могут давать ошибки; слабые совпадения требуют подтверждения темы.
- Исторические диагностические результаты13/16 и5/8 относятся к предыдущему проходу, использовались при разработке и не являются оценкой независимой точности. Текущий состав может отличаться; на защите лучше показать реальные запросы и честно объяснить ограниченный каталог.
- Проверки включают технические инварианты SVG, проекта, API и настоящую модель. Дополнительно проверены чистая установка, реальное скачивание SVG/JSON и открытие скачанного проекта с совпадением трансформаций.
- Разработка выполнялась с OpenAI Codex. На обсуждении важно разбираться в этих решениях и честно назвать использованные AI-инструменты.
