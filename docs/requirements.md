# Карта соответствия заданию

| Требование | Реализация и доказательство |
|---|---|
| Веб-сервис или Figma-плагин | Основной результат — локальная веб-студия, START.cmd, dist/index.html. Плагин экспериментальный. |
| Только предоставленная графика | source/library-S.svg, library-L.svg → assets/catalog.json; сохранены 3024 path d в 40 вариантах. |
| Геометрия и относительные размеры | Исходные внутренние координаты, внешний translate/rotate и единый scale всех предметов. tests/core.test.mjs. |
| Ввод заголовка/метафоры | Локальная MiniLM, описания тем и предметов, уточнение слабого результата. tests/semantic.test.mjs. |
| Явный ввод компонентов | Названия, словоформы, узкие синонимы и исключения; неизвестные слова видны после сборки. |
| Автоматическая композиция | Три варианта, смысловой центр, правила пар и общая нормализация. Главные предметы защищены от чрезмерного перекрытия в сценах из 2–5 экземпляров. |
| Настоящие S/L и состояния | 10 предметов × 2 состояния × 2 детализации; исходная геометрия различается. |
| Три схемы и своя палитра | Исходные схемы и проверяемый JSON; акценты предметов не попадают в декоративный фон. |
| Ручное редактирование | Move, rotate, duplicate/delete, главный/фоновый, z-порядок, undo/redo. |
| Форматы | Обложка, квадрат, постер, собственный размер от 200 до 4096 px. |
| Редактируемый экспорт | SVG из исходных путей, отдельные группы, уникальные ID, без image/script. Пример 02-savings.svg импортирован в браузерную Figma, отдельная группа кошелька перемещена на 10px; demo/figma-import-proof.png. |
| Репозиторий и архитектура | Приватный GitHub, README и architecture.md; работодателю нужен отдельный доступ. |
| AI-инструменты | Разработка: OpenAI Codex; runtime: pretrained MiniLM/Transformers.js. Новая графика не генерируется. |
| 2–3 композиции | Три SVG и реальные результаты selector в examples/selections.json. |
| Короткая демонстрация | demo/walkthrough.mp4 — непрерывные 90 секунд работы отдельного окна без звука. demo/demo.mp4 — дополнительный 35-секундный пошаговый показ. |

Ограничения смыслового качества и фактически выполненные проверки: ../qa/FINAL_VERIFICATION.md. Карта отличает реализованное поведение от ещё не выполненного сценария проверки.
