# Проверка SVG в Figma

Импорт и ручная правка в живой Figma пока не подтверждены. Браузерный инструмент создал отдельный пустой файл, но управление меню не завершилось. Исходный файл работодателя не изменялся.

Для проверки вручную:

1. Создать отдельный дизайн-файл в своей рабочей области Figma.
2. Перетащить examples/02-savings.svg на холст либо использовать Place image/video. SVG должен импортироваться как векторные слои.
3. Раскрыть иерархию, выбрать кошелёк или монету отдельно. Переместить предмет, затем выбрать один контур и поменять заливку. При необходимости разгруппировать импорт.
4. Сохранить скриншот и записать короткий фрагмент с видимой иерархией и изменением. Только после этого считать этот сценарий проверенным.

Официальная справка: [Add images and videos to designs](https://help.figma.com/hc/en-us/articles/360040028034-Add-images-and-videos-to-designs). Figma описывает преобразование SVG в редактируемые векторные слои; это описание формата не заменяет проверку нашего файла.
