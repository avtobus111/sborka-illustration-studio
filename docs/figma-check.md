# Проверка SVG в Figma — выполнена

3 ноября 2026 пример examples/02-savings.svg импортирован штатным Place image/video в отдельный браузерный файл Figma. Исходный файл задания не изменялся.

В дереве появились frame 02-savings 1080×1080, Clip path group, группы object-3 и object-4, вложенные векторные слои. Кошелёк object-3 выбран отдельно. Его X изменён клавишей Shift+Right с 73.713684 до 83.713684, Y361.084656; размеры 792.48×498.18 сохранены. Тем самым подтверждены импорт и возможность продолжать редактирование отдельного предмета.

Снимок: ../demo/figma-import-proof.png. Проверочный файл: https://www.figma.com/design/YUPvpMRKXfAN05jPqfvkIt/Untitled?node-id=2-15 . Его доступ не расширялся; ссылку получает владелец. Скринкаст веб-студии снят отдельно и не содержит саму операцию импорта.

Проверка не означает сертификацию каждого возможного SVG, правку всех контуров или проверку экспериментального плагина. Desktop-хост не использовался.

Официальная справка по механизму импорта: [Add images and videos to designs](https://help.figma.com/hc/en-us/articles/360040028034-Add-images-and-videos-to-designs).
