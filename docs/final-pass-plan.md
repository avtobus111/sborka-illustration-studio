# Финальный проход — 3 ноября 2026

Продолжаем существующий проект после согласия пользователя. Сначала воспроизводим установку из ZIP без node_modules/models, затем закрываем SVG/JSON через UI без ожидания download event, которое ранее заблокировало инструмент. Тестовые окна и сетевые ожидания ограничиваем.

Диагностический набор 16 новых запросов: исходный результат 7/16 по заранее заданным наборам предметов. Это ручные критерии полезности, не оценка точности на независимой выборке. После использования для разработки набор больше не называется отложенным.

Смысловой слой: сохранить encoder и 12 широких намерений, но выбирать состав по отдельным описаниям 10 предметов и частям составного запроса. За намерением остаются 1–2 обязательные смысловые опоры, остальная сцена формируется по релевантности. Не расширять списки точных пользовательских фраз. Слабые результаты требуют уточнения, неподдерживаемые остаются пустыми; новые предметы модель не создаёт. Выдавать heroId и краткие причины выбора.

Композиция: учитывать heroId и добавить ограниченные правила пары телефон/пазлы, кошелёк/монета, книга/лампа. Поддержать отрицательные локальные координаты через нормализацию общих границ, затем единый scale и перенос в разрешённую область. Импорт проекта сохраняет heroId; старая версия без него работает.

Проверки до кода: комбинированные запросы, выход только из каталога, роли/причины/heroId, отсутствие регрессий неподдерживаемых тем; геометрические инварианты всех трёх пар в S/L и трёх форматах; roundtrip heroId. После — диагностический набор повторно, небольшой новый независимый набор, один review, обновление демо/архива/приватного GitHub и краткий документ для защиты проекта.
