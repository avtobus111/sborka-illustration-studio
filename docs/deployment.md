# Публикация демо на Render Free

Приложение использует один Node.js-сервер: интерфейс, локальную ONNX-модель и экспорт. Внешний AI API, ключи и база данных не нужны. Файлы модели загружаются в сборку из закреплённой ревизии с проверкой SHA-256.

## Параметры Web Service

- Repository: https://github.com/avtobus111/sborka-illustration-studio
- Branch: main; Root Directory: оставить пустым.
- Runtime: Node; Instance Type: **Free**.
- Build Command: `npm ci && npm run setup:model && npm run build`
- Start Command: `npm start`
- Health Check Path: `/healthz`
- Environment: `NODE_VERSION=22.23.2`, `HOST=0.0.0.0`, `NODE_ENV=production`, `MALLOC_ARENA_MAX=2`.
- PORT задаёт Render; вручную не переопределять. Auto-Deploy: Off, чтобы изменения репозитория не меняли демо без ручного деплоя.

Те же параметры заданы в [render.yaml](../render.yaml), включая явный `plan: free`. Платный сервер или отдельный домен для тестового не требуются. Если форма предлагает платный тариф, выбрать Free до создания сервиса.

## Проверка после деплоя

1. `/healthz` должен вернуть HTTP 200 и `{"ready":true}`; пока модель не готова, он возвращает 503.
2. Открыть выданный Render HTTPS-адрес без авторизации. Дождаться «Модель готова».
3. Собрать «Найти общий язык» (телефон и пазлы), «Копить на мечту» (кошелёк и монета).
4. Проверить S/L, палитры, формат, поворот и порядок слоёв, undo/redo.
5. Скачать SVG и JSON; открыть сохранённый JSON в студии. Перезагрузка страницы должна восстанавливать локальный черновик.

На Free после 15 минут без входящих обращений сервис засыпает. Первое открытие после простоя может занимать около минуты и дополнительное время подготовки модели. Модель скачивается при сборке, не на каждый запрос. Черновики сохраняются в браузере посетителя; собственные загружаемые файлы сервер постоянно не хранит.

Локальный запуск без HOST остаётся на `127.0.0.1:4173`. Настройка `HOST=0.0.0.0` нужна для облачного сервера.

Память: на Windows перед публикацией измерено около 461 МиБ RSS на четырёх запросах; это не замер Linux и не гарантия попадания в лимиты Free. Публичный адрес можно считать готовым к передаче только после проверки работающей модели на Render.
