# Устранение замечаний аудита

Пользователь поручил закрыть замечания после проверки соответствия ТЗ. Приоритет — смысловой подбор, ссылка на репозиторий, короткая демонстрация.

## Решение

Вместо расширения списка ключевых слов: локальный pretrained sentence encoder Xenova/paraphrase-multilingual-MiniLM-L12-v2 (quantized ONNX) через Transformers.js 3.8.1 в Node.js. Целая фраза сравнивается с описаниями смысловых тем библиотеки. Выход — только существующие ID, роли и объяснение. Изображения модель не генерирует. Явные названия компонентов обрабатываются прежним детерминированным способом.

Альтернативы: облачный LLM требует ключа и внешнего сервиса; чистый словарь уже не прошёл аудит. Выбор локальной модели сделан агентом для запуска без API-ключей и без отправки запросов за пределы машины.

Сервис обслуживает UI и POST /api/select, GET /api/status. Веса скачиваются штатным setup-скриптом из конкретной ревизии Hugging Face, кэшируются в models/. После подготовки inference работает без сети. Нет молчаливого отката на старый словарь: при отсутствии модели UI сообщает проблему, оставляя явный выбор объектов доступным.

Дополнительно: улучшенная автоматическая композиция с главным/поддерживающим планом и единым масштабом, три примера получены тем же работающим движком, короткая видеодемонстрация и сценарий сдачи. Окончательная ссылка на репозиторий добавляется после подтверждённого доступа GitHub.
