# Illustration Studio Implementation Plan

Исторический план первой версии. Актуальная архитектура — в architecture.md; устранение замечаний аудита и локальная модель — в semantic-upgrade.md. Указания ниже о словарном смысловом подборе и esbuild не описывают итоговую сборку.

> Execution: inline in this session, prioritizing the user's request to finish as quickly as possible.

**Goal:** Рабочая автоматическая сборка исходных SVG с экспортом и редактированием.
**Architecture:** catalog → semantic selection → shared-scale layout → SVG serializer → browser / Figma adapter.
**Tech Stack:** JavaScript ES modules, native SVG/DOM, esbuild; Python/svgpathtools только для извлечения исходников.
**Spec:** docs/design.md

## Global Constraints
- Только исходные объекты Figma; без растра.
- Версии S/L; единый масштаб всех объектов внутри композиции.
- Три схемы и импорт палитр; фон использует только фоновые цвета.
- Подбор по смысловому словарю честно обозначен; неизвестные запросы обрабатываются явно.

## Review Focus
- Пустой/неизвестный запрос: понятная ошибка без ложного успеха.
- Ручной перенос и переключение роли сохраняют исходные пропорции.
- Некорректная палитра отклоняется, текущая сцена остаётся.
- Переключение S/L использует реальные различные векторы.
- Экспорт открывается независимо от приложения, ID уникальны, image/script отсутствуют.
