# Конструктор векторных иллюстраций

Основание: файл Figma 4MCFttsSoP7hgQh29zq5G3, страницы Задание, Библиотека компонентов, Примеры композиций, просмотрены 2026-11-02.

Цель: запускаемый проект для тестового. Два входа: заголовок/метафора и явный набор объектов. Автоматическая раскладка под формат; ручная корректировка; палитра; SVG-экспорт.

Подходы: отдельный веб-редактор проще показать, плагин Figma использует готовый холст. Выбранное агентом решение в рамках согласованного старта: общий SVG-движок с браузерной демонстрацией и адаптером Figma. Desktop Figma сейчас не установлен; проверка в живом хосте будет отдельной границей достоверности.

Исходные объекты извлекаются из реальной SVG-выгрузки S/L с идентификаторами. Пути не перерисовываются. Объекты меняют только положение, поворот, роль и цвета; общий масштаб для всей композиции сохраняет относительные размеры. Нельзя добавлять сгенерированные иллюстрации или растрировать.

Текущее решение: локальный pretrained MiniLM sentence encoder сопоставляет целую фразу с описаниями 12 тем библиотеки. За темами закреплены существующие предметы и роли. Внешний AI API и ключ не нужны. Слабый или неподдерживаемый запрос может быть отклонён; сложные метафоры и контекст могут пониматься ошибочно. Объекты также можно выбрать явно. Ранний словарный подбор заменён после аудита; его нельзя считать актуальным смысловым режимом интерфейса.

Палитры: три исходные, импорт JSON с отдельными массивами background и objects. Фон ограничен background; объекты могут пользоваться обеими группами. Разделение цветов главных/фоновых вариантов сохраняется.

Интерфейс: рабочая студия, светлые панели, тёмно-синий акцент, центральный крупный холст, исходная графика ведёт. Русский язык. Библиотека слева, параметры/слои справа; компактная версия для окна плагина. Никаких вымышленных показателей и маркетинговых секций.

Сдача: исходники, собранный HTML, инструкция запуска, архитектура, список AI-инструментов, три SVG-примера и короткий показ результатов. Самостоятельный браузерный сервис — основная платформа; Figma-адаптер экспериментальный. Пользователь выбрал приватный GitHub-репозиторий; доступ работодателю выдаётся отдельно.
