# Решение тестового

Основная платформа — самостоятельный локальный веб-сервис. Это один из разрешённых заданием вариантов. Библиотека извлечена из предоставленных SVG S/L; новые иллюстративные объекты не создаются. Сохраняются исходные path d, геометрия внутри групп и относительные размеры через единый равномерный масштаб.

Два входа: метафора/заголовок и названия компонентов. MiniLM кодирует запрос и части фразы; широкие намерения задают опоры, описания отдельных предметов уточняют состав. Именованные предметы и исключения имеют приоритет. Чистое перечисление разбирается детерминированно. Неподдерживаемый запрос может быть отклонён; слабый результат предлагает выбор темы. Это поиск по ограниченной библиотеке, не универсальная генеративная модель.

Автоматические варианты сохраняют формат, S/L и палитру. Смысловой центр и несколько правил пар задают композицию; главные предметы защищены от чрезмерного перекрытия. Вертикальный постер phone/puzzle строится вдоль высоты. Пустая зона под заголовок — отдельное расположение. Любая автоматическая перекомпоновка сбрасывает ручные позиции и повороты; отмена возвращает их.

Пользователь меняет положение, поворот, состояние и порядок слоёв, дублирует и удаляет предметы. Три исходные палитры и импорт JSON перекрашивают сцену с разделением фоновых и объектных цветов. SVG содержит исходные векторные группы; JSON переносит редактируемый проект между сессиями. Чертёж интерфейса и визуальные правила — ../DESIGN.md.

Комплект: README, архитектура, карта требований, 70 автоматических проверок, три SVG-примера и демонстрация. Figma-адаптер экспериментальный. SVG-пример импортирован в браузерную Figma, отдельный кошелёк перемещён на 10px. Непрерывный 90-секундный показ веб-студии сохранён отдельно; сама операция импорта в этот ролик не входит. Исторические планы находятся в archive/.
